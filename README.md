# AI-Resilient Assessment & Intelligent Feedback Platform

A next-generation programming assessment environment designed for the generative AI era. Instead of relying on brittle AI text detectors, the platform employs **architectural resilience** and **multi-tiered pedagogical feedback**.

---

## 🌟 Key Architecture & Capabilities

### 1. Architectural AI Resilience
* **AI Viva Voce (Socratic Oral Defense Modal):** Upon submitting code, learners undergo an adaptive 3-question defense interrogating their implementation choices, edge-case assumptions, and architectural tradeoffs.
* **Process & Epistemic Telemetry:** Tracks keystroke cadence, paste ratios, active typing duration, and burst anomalies to differentiate organic iteration from bulk clipboard drops.
* **Inverted & Evaluative Assessment Tasks:** Challenges include auditing and refactoring subtly flawed code generated by LLMs (e.g. ReDoS vulnerabilities, context-free grammar parsing bypasses).

### 2. Multi-Tiered Intelligent Feedback Engine
* **Misconception Diagnostician:** Identifies flawed mental models (e.g. *Single-Pass Token Elimination Fallacy*, *Array Shifting Disqualification for O(1) Invariant*, *System Time Monotonicity Assumption*) rather than generic compiler errors.
* **Progressive Socratic Scaffolding:**
  * **Tier 1 (Cognitive Nudge):** Directs learner attention without giving away implementation logic.
  * **Tier 2 (Socratic Guiding Question):** Questions the core invariant or boundary condition being violated.
  * **Tier 3 (Structural Remediation):** Provides targeted architectural guidance unlocked only after productive struggle.
* **Rubric-Anchored Evaluation:** Breaks scores into exact criteria with evidence citations.
* **Asymptotic Profiling:** Tracks time and space complexity invariants.

## 🚀 Quickstart

### Prerequisites
* Node.js >= 18.x
* npm >= 9.x

### Installation & Run
```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open in browser
# http://localhost:3000
```
